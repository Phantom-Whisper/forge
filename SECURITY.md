# Security Policy


## Supported Versions
| Version | Security |
|---------|-----------|
| < 1.0 | No security support |

## Reporting a Vulnerability

If you discover a vulnerability:

1. Do not disclose it publicly.
2. Contact the maintainers privately.
3. Include steps to reproduce the issue.
4. Allow reasonable time for investigation and remediation.

Do not include sensitive user information in reports.

If you think you dispose of a reliable way of solving the vulnerability, please report to the [CONTRIBUTING](CONTRIBUTING.md) section.
